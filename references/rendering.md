# 离线绘制与检查

## 复用渲染入口

在 GalGear 中，使用 core 现有渲染流程将结构化结果生成单文件 `route-map.html`。模板来自 `web/route-map.html`、`web/route-map.css` 和 `web/route-map.js`，数据由本地代码安全嵌入。先查 `crates/core/src/ai_summary/skill_analysis.rs` 中的 `route_html::render` 调用，沿现有入口生成。

保留模型输出为结构化数据，使用固定、可信的渲染器处理布局与转义。HTML/SVG 数据按其上下文转义，嵌入 JSON 时防止源文本闭合脚本标签。样式、脚本和字体使用本地内嵌资源，生成物可离线打开。

已有 HTML 或 SVG 输出格式时沿用项目入口。独立任务按用户指定格式交付。需要实现交互视图时，使用下面的布局规则。

## 布局与阅读

- 箭头从上往下接入节点和选项。同列用一根竖线，错列用水平横杆连接两侧的竖线。标签行留给竖线，横向转折安排在标签行外。普通推进画无标签箭头。真实玩家选项显示原文，条件和解锁显示其触发条件。查看每个必经选择点前后的连线，确认只有具备独立跳转依据的路径可以绕过它。
- 主图使用剧情标题与玩家选项原文，来源坐标、原始条件标记和证据放在详情中。
- 展开后按节点、选项标签和连线各自占用的纵向范围计算横向间距。短分支结束后的空间可以放相邻分支的后续节点，避免整棵子树的宽度把浅层选项推远。标签换行后按实际高度分配空间。
- 保持同一分岔点的选项顺序，给纵向范围相交的内容留出横向间距，并检查分岔连线是否穿过相邻分支的节点或标签。
- 同一决策的同目标选项并排显示，每条箭头从自己的标签进入同一剧情框的不同位置。其他分支已有的子树和真实回跳可使用定位引用。独立入口从同层开始布局。
- 在选项原文旁标出该选项的每个已知数值变化，计入标签宽高和折行。展开、折叠以及导出文字攻略时保留数值与选项的对应关系。
- 推断连接使用虚线等明确标记并提供图例。已证实的断开结构按实际状态展示。
- 条件分流先呈现判定，再在对应分支下呈现剧情。EXTRA 与有依据的前置结局关联，GRAND 保留独立类型。
- 默认收起普通线性剧情，包括同一菜单的选项共同经过的短场景。各选项沿独立箭头到下一个有效节点，原文、数值变化、条件和推断状态随箭头保留。场景与跳转证据按原顺序放进详情。在 GalGear 中点击箭头所指的节点可查看各条入边。不同主线分支的真实合流、路线入口、截断位置和回跳锚点保留为节点。

GalGear 交互视图支持折叠时保持点击位置、全部展开、适应宽度、缩放、鼠标/触摸拖动、键盘导航和明暗主题。窄屏默认展开两层，引用按钮可展开并聚焦目标。遵循系统减少动态效果偏好。

## 检查生成物

先完成图结构校验，再实际打开最终输出。

1. 全部展开，核对每个保留节点只有一份完整内容。原有选项全部保留，收起的场景和跳转可从箭头详情回查。
2. 检查节点与标签无重叠，长文本可读，跨分支连线与回跳方向明确。确认 SVG 连线只使用水平和垂直指令，箭头从节点顶部垂直进入。
3. 折叠和展开后检查点击锚点，逐个测试引用跳转能聚焦真实目标。
4. 检查宽窄窗口、明暗主题和键盘操作。确认页面未发起外部资源请求。
5. 修改数据或布局后重新生成并复查相关项目。

GalGear 的 `scripts/check-route-map.js` 是在已打开页面的浏览器上下文执行的检查脚本，检查完整节点、边数量、元素重叠、折叠锚点、引用焦点和离线资源。执行后结合实际页面确认视觉结果。终端直接运行该脚本不具备所需 DOM 环境。

修改 GalGear 布局时，先运行 `scripts/build-frontend.ps1`，再执行 `cargo test -p galgear --locked native_route_view_preserves_controls_and_exports -- --ignored --test-threads=1 --nocapture`。默认夹具在窄窗口中检查深主线旁的短分支。可以通过 `GALGEAR_TEST_ROUTE_EXE` 指定含已有路线缓存的游戏复核真实路线。对比排版宽度时，用同一份图数据计算全部展开后的未缩放画布宽度。

输出文字攻略或 JSON 草稿时，按入口、选项、结局和前置条件组织，并附未确认项。若交付第三方站点导入文件，先依据该站点实际协议验证兼容性。

## 个人线与进度定位

点击某条个人线的专属节点或通过路线选择器选线，同步突出共通线中有依据的选项、箭头、入口和线内剧情，并淡化其他路线。支持切换角色、跳到入线选项、恢复全图及键盘操作。只有连通关系时标明具体组合待确认。存档信息置于图外，定位时标记匹配的剧情节点。匹配点已折叠时，保留原坐标，并将标记放在这一段前方的可见节点。读取旧图应接回经过存档项的剧情和选项。
